*************Apex Homework – Week 4, Day 1: Validation Rules***************************************

validation rule : Validation Rule: A validation rule is used to check whether the data entered by a user is valid before saving the record.

If the condition is true, Salesforce shows an error and does not save the record.

Example:

Account Phone must not be blank.

----------------------------------------------------------------------------------------


 Create all Validation Rules directly in Salesforce Setup (Object Manager → Validation
Rules).
